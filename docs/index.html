Quick Start

from riskpilot.evaluation import BinaryPerformanceEvaluator
# Assume you already have df_train/test with predictor columns + 'default_90d'

model = joblib.load("clf.joblib")   # any estimator with predict_proba()

eval = BinaryPerformanceEvaluator(
    model=model,
    df_train=df_train,
    df_test=df_test,
    target_col="default_90d",
    id_cols=["contract_id"],
    date_col="snapshot_date",   # enables time‑series plots
    save_dir="figs"              # auto‑saves PNGs/HTML if save=True
)

# 1. Core metrics (MCC, AUC, Brier …)
print(eval.compute_metrics())

# 2. Visual diagnostics
_ = eval.plot_confusion(save=True)
_ = eval.plot_calibration(display=True)
rate, share = eval.plot_event_rate(separated=True)

# 3. Explainability
shap_bar = eval.plot_shap(plot_type="layered", summary=True)
shap_bar.show()

# 4. Stress‑test with synthetic vintages

Key Features

  • Metrics – MCC, AUC‑ROC/PR, Precision, Recall, Brier / per period.
  • Visuals – Confusion, Calibration, KS evolution, PSI, Event‑Rate, Histograms, Decile KS.
  • Homogeneous groups – automatic (OptimalBinning) or custom n‑quantiles.
  • Drift detection – PSI thresholds & histogram drift highlighting.
  • Explainability – unified SHAP wrapper (Tree/Linear → Kernel fallback with friendly log).
  • Caching – opt‑in SHAP cache (use_cache=False by default).
  • Stress‑testing – plug any synthetic generator via LookAhead.
  • Report export – single call bundles figures, CSV, TXT insights & ZIP.

High‑level API

MethodDescription
compute_metrics(by_date_col=False)Return DataFrame of MCC, AUC, Precision, Recall, Brier.
Set by_date_col=True for vintage metrics.
plot_confusion()Side‑by‑side confusion matrices with KS/Youden threshold option.
plot_calibration()Reliability curves (train / test / val) with Brier score in subtitle.
plot_event_rate()Bad‑rate & share by homogeneous group. separated=True → one subplot per split.
plot_histograms()Distribution drift with PSI/KS annotation, KDE fill, legend toggle & drift bars.
plot_psi()PSI over time for 1 or N features, smart‑view, thresholds 0.10 / 0.25.
plot_ks()KS per vintage with 0.20 reference line.
plot_group_radar()Radar chart of scaled feature means per GH – combined / separated / animated.
plot_decile_ks()Decile analysis wrapper with KS & cumulative gains.
plot_sankey_migration()GH migration flows between periods (period→period or net).
plot_shap(**)Unified entry – bar, layered, beeswarm, dependence, trend, waterfall.
run_stress_test()Generate synthetic vintages & run selected eval functions.
export_report()Persist figs, CSV summary & bullet insights (optionally zipped).

FAQ

Install the static image backend:

pip install kaleido
"No module named shap"

Install the viz extra:

pip install riskpilot[viz]
Why is KernelExplainer slow?

BinaryPerformanceEvaluator automatically chooses Tree or Linear explainers when available. The SHAP cache (use_cache) is disabled by default – enable it via eval._compute_shap_values(..., use_cache=True) or set --use-cache in your CLI script to speed‑up repeated calls.

My notebook cell never finishes

Check the logs for a warning that shap.KernelExplainer was used. This fallback can be extremely slow. Switch to a tree or linear model or sample your data.
